# PUBLIAVISO C.A. — Landing V2 / Prototipo funcional

Prototipo front-end de la maqueta V2 aprobada para revisión de operatividad.

## Cómo ejecutar

No requiere Node, PHP ni servidor para esta revisión.

1. Descomprimir el ZIP.
2. Abrir `index.html` en Chrome, Edge u Opera.
3. Revisar navegación, responsive y formulario.
4. Para probar el formulario, el navegador abrirá el cliente de correo mediante `mailto:`.

También puede ejecutarse con cualquier servidor estático local.

## Activos

Se utilizaron el logo original suministrado en la conversación, el emblema de 70 años y las imágenes reales disponibles del sitio base para las seis líneas técnicas.

El mapa se conserva como **mapa base temporal** hasta incorporar la versión gráfica definitiva con la cobertura aprobada:
- Norte: Caracas · Miranda · La Guaira
- Oriente: Anzoátegui · Monagas
- Sur: Bolívar · Faja Petrolífera del Orinoco

La fotografía histórica definitiva del Puente de Angostura y fotografías finales de proyectos deben sustituirse cuando se incorporen los archivos originales aprobados.

## Importante

Este paquete es un **prototipo funcional de front-end**, no la publicación definitiva. No contiene backend, CRM, WhatsApp API ni almacenamiento de formularios.
